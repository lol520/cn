# 保险内容视频 · 风格描述 Skill

## 为什么要这个 Skill
同一篇稿子，视觉写得越具体，AI 出片越稳定。“做得高级一点”这种话会让每次结果都不一样；把配色 hex、字号、进场时长、组件都写死，才能批量出同一个账号风格。这个 Skill 把风格固定成 20 个模板，每次只需要选一个、填稿子。

## 使用流程
1. **读稿判断内容类型**：科普 / 测评 / 对比 / 理赔解读 / 避坑 / 数据 / 金句 / 新闻热点。
2. **选模板**：按下方“快速选择表”推荐 1 个主模板，说明理由；用户指定编号就直接用。
3. **输出风格规格卡**（按“规格卡格式”），给用户确认或直接进入制作。
4. **拆分镜**：每个分镜 4–8 秒，一屏只讲一个点，正文每屏不超过 2 条、每条不超过 28 字。
5. **写 HyperFrames 代码**：字体本地打包（如 Noto Sans SC），GSAP 本地引用，所有动画挂在 `window.__timelines["main"]`。
6. **先截图再渲染**：`npx hyperframes snapshot --at <各分镜中点>` 检查换行、溢出、对比度，没问题再 `render`。

## 保险内容硬规则（任何模板都要遵守）
- 字幕和画面文字避开违禁词（2026-10-13 喵叔要求）：回本、取钱/取出来花、利息、本金、保本、稳赚、零风险、收益/收益率、比存款、停售/窗口期、最高/第一/唯一。口播照原样，字幕换说法（回本→现价超过已交保费；取钱→领取/减保领取）。交付前对 subs+卡片文字跑一遍违禁词扫描。
- 不写收益承诺、不写“保本”“稳赚”“最好的保险”“第一”“TOP1”“顶流”“底气”等营销/绝对化用词。
- 分红实现率、IRR 照常可用（2026-10-13 喵叔确认，未收到平台禁用通知）；含分红的 IRR/现金价值一律标“演示利益，含不保证红利，以合同为准”。
- 真人口播的圆形小窗：脸必须在小窗正中（2026-10-13 那条因固定锚点偏右下）。喵叔的脸一般不会偏离初始位置太远，不做逐帧追踪：开头取几帧定好脸的中心，按此固定裁切，交付前抽帧核对居中。
- 封面：真人口播视频的封面用他真人圆窗（脸居中）+本条配色，默认出 9:16 和 3:4，标题、数据和免责小字同样过违禁词扫描。
- 画面、标题、字幕、口播都不出现“收益”“收益率”“回报率”“复利”“排行榜/排名/榜单”“升值”“躺赚”等词（抖音/小红书金融内容违规话术）。替代：收益率→IRR 或“现金价值增长”；排行榜→横向对比/对比表；10年单利、IRR 等数值需注明“含分红演示，分红不保证”。
- 不给产品标前三名、冠军等名次视觉（序号只做编号，不做奖牌/高亮）。
- 写「一次性缴清」，不写「一次性交清」；「趸交」可以用。
- 产品名、公司名保留真实名称；数据必须标来源和时间（如“条款第X条”“2026年X月费率表”）。
- 理赔案例只用本人或本人客户的真实案例，不用别人的案例。
- 测评/对比结构：痛点 → 对比 → 怎么选；讲“产品解决什么问题”，不写“我们来对比一下”。
- 不用“首先/其次/最后”这类列举转场；结尾不写“行动建议”式口号，卡片上不加无意义的口号页脚。
- 片尾固定一屏小字免责声明：「内容仅为保险知识科普，不构成投保建议，具体以保险合同条款为准。」
- 品牌固定写「喵叔说保」；深色背景上的头像必须垫米白（#F3F1EC）圆底，否则透明头像会看不见。
- 分红险数据每屏或至少片头/片尾标注：含分红演示、分红不保证、仅作横向参考，并写清测算口径（如 30岁男、趸交）和整理时间。
- 若内容涉及具体产品推荐/销售，需确认已取得所属机构授权；否则只做科普。

## 规格卡格式（每次输出都用这个结构）
```
模板：#编号 名称
画幅：16:9 1920×1080 / 9:16 1080×1920
配色：背景 #… 主文字 #… 强调色 #… 辅助色 #…
字体：标题 Noto Sans SC 900 / 正文 Noto Sans SC 500；标题字号… 正文字号…
版式：（例：左标题右卡片 / 居中大字 / 上标题下表格）
核心组件：（例：荧光笔高亮、剪报卡、对比表、进度条、印章）
动效节奏：进场方式 + 时长（例：标题擦除 0.7s，卡片 0.8s back.out，条目间隔 1.3s），转场方式
每屏密度：标题 ≤8 字，正文 ≤2 条，每条 ≤28 字
片头/片尾：…
禁止：…
```

## 20 个风格模板

### #1 荧光笔笔记
- 适合：条款科普、概念讲解。信息清楚、亲切、像老师划重点。
- 配色：米白纸 #F8F6EF / 墨黑 #1B1B1B / 荧光黄 #FFC93C / 蓝点 #2F5BD3 / 编号淡红 #E4473B 12%透明
- 版式：左上小标签 + 大标题，下方白卡片（4px 黑边 + 12px 实心投影），右上超大淡色编号。
- 动效：标题上移淡入 0.6s，荧光笔从左到右刷 0.6s（background-size 0→100%），卡片上浮 0.7s，条目间隔 1.4s。
- 禁止：渐变色、阴影模糊、emoji。

### #2 新闻台警示
- 适合：避坑提醒、热点解读、行业新规。压迫感强，像“新闻大写”。
- 配色：深蓝黑 #0E1116 + 80px 细网格 / 白字 #F2F2F2 / 警示红 #E5262B / 灰字 #AEB4BE / 剪报纸 #F4EFE3
- 版式：顶部频道条（红色标签 + 栏目名），左侧标题+一句注解，右侧倾斜 -1.5° 的剪报卡，底部红色滚动字幕条。
- 动效：标题 clip-path 擦除 0.7s power4.inOut，剪报从右甩入 0.8s back.out，关键词红底逐个铺开，字幕条匀速滚动。
- 禁止：卡通元素、圆角大于 8px。

### #3 测评打分卡
- 适合：单款产品测评。
- 配色：浅灰 #F2F4F7 / 深墨 #111827 / 分数绿 #16A34A / 扣分橙 #F59E0B / 不足红 #DC2626
- 版式：左侧产品名+公司名+测评日期，右侧 5 个维度横向进度条（保障范围、免责条款、健康告知、续保、价格），最后一屏总评。
- 动效：进度条从 0 长到分值 0.8s power2.out，数字同步 count-up，维度间隔 0.4s。
- 禁止：五星评分图标、“强烈推荐”字样。

### #4 对比擂台
- 适合：2–3 款产品同维度对比。
- 配色：白 #FFFFFF / 左方蓝 #2563EB / 右方橙 #EA580C / 中线灰 #E5E7EB / 文字 #0F172A
- 版式：左右分屏，中间竖线和维度名，每行一个维度，胜出项加粗+小勾。
- 动效：左右两栏同时从两侧滑入 0.6s，维度逐行亮起，间隔 1.0s；胜出项轻微 scale 1.05 回弹。
- 禁止：“完胜”“吊打”等字眼；必须同口径（同年龄、同保额、同缴费期）。

### #5 案卷档案
- 适合：理赔案例复盘（仅用本人/客户案例）。
- 配色：牛皮纸 #E8DCC2 / 档案深棕 #3B2F2F / 印章红 #B91C1C / 打字机灰 #4B5563
- 版式：档案袋封面 → 打开后一页页“材料”：出险经过、提交材料、理赔结果，右下角盖章。
- 动效：纸张翻页 rotateY 0.8s，文字逐字打出（每字 0.03s），结果页印章从大到小砸下 0.4s。
- 禁止：真实姓名、身份证号、病历照片；客户信息一律脱敏。

### #6 黑板讲解
- 适合：基础知识、计算逻辑（如现金价值、保额递增怎么算）。
- 配色：黑板绿 #1F3B2D / 粉笔白 #F5F5F0 / 粉笔黄 #F6E27A / 粉笔粉 #F4A7B9
- 版式：整屏黑板，标题在上，公式/箭头手绘感（SVG 描边动画）。
- 动效：SVG stroke-dashoffset 描线 1.0s，文字淡入 0.4s，重点画圈。
- 禁止：真实手写字体文件过大导致渲染慢，标题仍用黑体。

### #7 数据仪表盘
- 适合：费率、保额、医疗费用、赔付率等数字。
- 配色：深色 #0B1020 / 卡片 #141B2E / 青 #22D3EE / 紫 #A78BFA / 白字 #E5E7EB
- 版式：2×2 数据卡，大数字 + 单位 + 来源小字；或单个大柱状/折线图。
- 动效：数字 count-up 1.2s，柱子从底部长出 0.8s stagger 0.15s，折线 stroke 描出。
- 禁止：没有来源的数字；每张卡必须有“数据来源/时间”。
- **多产品横向对比加强版（#7 + 一镜到底，2026-10-11 分红险30款定稿）**：
  - 适合：10 款以上产品、多年份数据（IRR、现金价值、领取金额）。时长 60–75 秒，比普通 30–40 秒版更能讲清。
  - 必须先给**全景**：所有产品全部上屏（每款一行，名字+公司+数值条），不能只挑几款展示；再按维度（如封闭期）重新分组、把重点产品标红、其余降饱和，重点讲完再恢复。
  - 结构参考：片头大数字（N款）→ 全景条形图（按某一年数值排序）→ 按封闭期等维度重排分组 + 重点产品单独拉出 → N×年份 热力图（每列最高值黄框）→ 结论横幅（“没有一款每年都最高”）→ 米白片尾卡（结论+logo+免责）。
  - 运镜：所有面板摆在一张大画布上，镜头连续推拉/扫视，不切场；落点用 expoInOut 快移 + 轻微震动，面板内小推近用 cubicInOut；镜头取景必须完整包住名字列，别切掉左侧产品名。
  - 洞察小卡放在面板右侧固定卡位，内容如“区间 1.71%–2.49%”“前9款只差0.11个百分点”“2年封闭两款与最高只差0.09–0.11个百分点”。
  - 颜色：封闭期 2年 #FF5A5F / 3年 #F5B83D / 4年 #22D3EE / 5年 #A78BFA；热力图 #13203F→#1E6FA8→#22D3EE→#FDE047；最高值框 #FDE047。

### #8 极简大字
- 适合：金句、观点、开场钩子。
- 配色：纯白 #FFFFFF / 纯黑 #000000 / 单一强调红 #FF3B30（每屏最多 2 个字）
- 版式：居中一行或两行超大字（160–220px），四周大量留白。
- 动效：逐字弹出 stagger 0.06s，停留 1.5s，整句上移淡出。
- 禁止：任何装饰元素、背景纹理。

### #9 红黄警示牌
- 适合：“千万别这样买”类强提醒。
- 配色：警示黄 #FACC15 / 黑 #111111 / 红 #DC2626
- 版式：黄黑斜纹边框，中间三角警示符号 + 标题，下方黑底黄字说明。
- 动效：警示牌左右轻晃 2 次 0.5s，斜纹缓慢平移，说明文字逐条闪入。
- 禁止：恐吓式话术（“不买就完了”）。

### #10 政策公文
- 适合：监管新规、条款变更、费率调整解读。
- 配色：公文白 #FFFFFF / 正文黑 #222222 / 红头红 #C8102E / 引用灰底 #F3F4F6
- 版式：红头标题 + 文号样式副标题，原文引用块（灰底左红线），下方“通俗说”解读卡。
- 动效：红头从上落下 0.5s，原文关键句逐句高亮，解读卡右滑入。
- 禁止：伪造文号；只引用公开文件原文并注明出处。

### #11 家庭关系图
- 适合：家庭保障规划、给谁先买、保额怎么分。
- 配色：暖白 #FFF8F0 / 节点深蓝 #1E3A8A / 连线灰 #CBD5E1 / 已保障绿 #10B981 / 缺口橙 #F97316
- 版式：中心是家庭，向外连出成员节点，每个节点旁标保障类型，缺口用橙色虚线。
- 动效：节点逐个 scale 弹出 0.4s，连线描出 0.6s，缺口节点脉冲闪 2 次。
- 禁止：真实家庭照片；用简洁图标。

### #12 体检报告
- 适合：保单体检、测评“健康告知/免责”项。
- 配色：医疗白 #FFFFFF / 医疗蓝 #0EA5E9 / 正常绿 #22C55E / 异常红 #EF4444 / 表格线 #E2E8F0
- 版式：报告单抬头 + 表格（项目 / 结果 / 参考说明），异常项红色箭头。
- 动效：表格逐行展开 0.3s，异常项红色闪烁 + 侧边批注卡滑入。
- 禁止：医疗诊断式结论。

### #13 表格逐行亮
- 适合：多维度参数表、条款对照。
- 配色：浅灰底 #F8FAFC / 表头深蓝 #1E293B / 高亮行浅黄 #FEF3C7 / 文字 #0F172A
- 版式：整屏表格，最多 5 行 4 列；当前讲的行高亮，其他行降到 40% 透明。
- 动效：高亮条在行间滑动 0.5s，单元格数字 count-up。
- 禁止：超过 5 行；超出拆成两屏。

### #14 字典词条
- 适合：一个专业名词一条视频（等待期、免赔额、现金价值、宽限期）。
- 配色：象牙白 #FAF7F0 / 墨黑 #1A1A1A / 词性红 #9F1239 / 例句灰 #6B7280
- 版式：大号词条 + 拼音 + 词性标签，下方“释义”“举例”“容易误解”三段。
- 动效：词条打字机出现，释义段落淡入，误解段用删除线划掉错误说法。
- 禁止：释义与条款原文冲突；以合同条款为准。

### #15 杂志封面
- 适合：系列开篇、年度盘点、封面金句。
- 配色：主色二选一（克莱因蓝 #002FA7 或 酒红 #7F1D1D）/ 白 #FFFFFF / 细线 #FFFFFF 50%
- 版式：超大期号/标题压在画面上，细线分栏，小字目录。
- 动效：大标题从画面外滑入 0.9s expo.out，目录逐行淡入。
- 禁止：堆砌英文装饰词。

### #16 爆炸图拆解
- 适合：产品结构拆解（主险 + 附加险 + 责任）。
- 配色：浅灰 #F1F5F9 / 模块色依次 #3B82F6 #8B5CF6 #14B8A6 #F59E0B / 标注线 #64748B
- 版式：一个整体方块（产品）→ 拆成几个模块悬浮分开，每块引出标注。
- 动效：整体先出现，随后模块向外散开 0.8s，标注线描出，逐个讲解时当前模块放大。
- 禁止：模块超过 5 块。

### #17 手账拼贴
- 适合：轻松科普、宝妈/家庭向内容。
- 配色：奶油 #FFF7E6 / 胶带粉 #F9A8D4 / 胶带蓝 #93C5FD / 文字棕 #44302A
- 版式：便签纸、胶带、贴纸式小图标拼贴，标题手写感（仍用黑体加粗，避免难读）。
- 动效：便签从上方“贴”下来带 2° 旋转回弹，胶带最后贴上。
- 禁止：花哨到看不清字；每屏最多 3 个装饰。

### #18 时间线
- 适合：理赔流程、等待期、缴费期、保单生命周期。
- 配色：白 #FFFFFF / 轴线深灰 #334155 / 节点蓝 #2563EB / 风险节点红 #DC2626
- 版式：横向时间轴，节点上方日期/天数，下方事件说明。
- 动效：时间轴从左向右延伸，镜头（整体 x 平移）跟着节点走，风险节点放大停留。
- 禁止：时间节点与条款不符。

### #19 流程图
- 适合：投保流程、理赔材料清单、核保步骤。
- 配色：浅蓝灰 #EEF2FF / 卡片白 #FFFFFF / 箭头靛蓝 #4F46E5 / 完成勾绿 #16A34A
- 版式：3–5 个步骤卡横排或 Z 字排，箭头连接，每步一个图标 + 一句话。
- 动效：步骤卡依次弹出，箭头描线，完成后打勾。
- 禁止：步骤超过 5 个。

### #20 编号清单
- 适合：“X 个常见误区”“X 个必看条款”。
- 配色：炭黑 #18181B / 编号金 #EAB308 / 白字 #FAFAFA / 分隔灰 #3F3F46
- 版式：每屏一个巨大编号（300px+）在左，右侧标题 + 一句解释；末屏汇总列表。
- 动效：编号从 0 翻牌滚到目标数字 0.6s，标题擦除进场，末屏列表 stagger 0.2s。
- 禁止：“排名”“榜首”“榜单”这类评价产品优劣的说法，只用于误区/要点编号。

## 通用技术约定（HyperFrames）
- 1920×1080 正文 ≥ 44px，9:16 正文 ≥ 48px；标题 100–160px。
- 字体文件放项目内并用 `@font-face` 引用，避免渲染机缺中文字体。
- 每个场景 `class="clip"` + `data-start` + `data-duration`；场景末尾 0.4s 淡出转场。
- 渲染前必跑 `npx hyperframes snapshot`，检查：字被截断、行尾单字、对比度不足。
- 有旁白时以音频时间轴为准重排 `data-start`，字幕另起一层。

## 封面（每条视频默认一起出）
- 三个比例：竖屏 9:16 1080×1920、横屏 4:3 1440×1080、竖版 3:4 1080×1440；风格与视频同一套配色。
- 元素：品牌眉题「喵叔说保 · 保险科普」+ 大标题（数字用强调色，如“30款分红险 横向对比”）+ 一句问句钩子色块（如“封闭期 2年 还是 5年？”）+ 2–4 个口径标签（趸交 / 30岁男 / 含分红演示）+ 头像 + 用真实数据画的小图（热力图/柱状）+ 底部一行小字免责。
- 用 HTML 写好后 Playwright 截图，检查不溢出、不换行断字再交付。

## 渲染经验
- 70 秒 1080p 带动态模糊约 12–15 分钟；多个渲染任务不要共用同一个帧目录，旧帧先清掉。
- 长渲染分段跑，支持断点续渲（只补缺失帧），避免中途被中断白跑。

## 默认动效（喵叔 2026-10-10 定的）
奶油纸点阵背景 #F8F6EF + 深色描边白卡片（5px #1B1B1B 边、8px 实心投影）+ 黄色荧光笔 #FFC93C + 红色强调 #E4473B。一个大画布放所有内容块，镜头一镜到底在块之间移动：段内小推移（cubicInOut，约0.85s），换段时先拉远到 0.55 倍再俯冲到下一段（expoOut）并带落地抖动（amp 9，1.2s 衰减），黄色墨线从上一块画到下一块。停留时镜头保留轻微动态（约 1.5–2% 缓推），喵叔 2026-10-12 确认这种轻微跳动可以保留。

## 长视频流水线（照 example-accident5 跑）
1. 文案 → `lines.txt`：一行一句口播（也是字幕），`#S 段名` 分段。可优化措辞，但不要砍短；遵守上面的保险硬规则。
2. `python tts_text.py` → `lines_tts.txt`：数字、单位转中文读法（298→二百九十八，100万→一百万），字幕仍用阿拉伯数字。
3. 配音：`PROJ=<项目目录> python ../voice/gen.py`。有 NVIDIA 显卡用 cuda+bf16，很快；纯 CPU 用 float32（bf16 在 CPU 上极慢），每句约 1–2 分钟，可用 BUDGET 分批断点续跑。语速超出 2.8–7 字/秒的自动重试 3 次。
4. **必须**逐句校对：`PROJ=<项目目录> python ../voice/check_asr.py`，把列出的句子 wav 删掉后重跑 gen.py，直到 BAD 为空或剩下的只是同音字差异（喵叔 2026-10-12 反馈过“部分台词语音对不上”，只查语速不够）。
5. `python assemble.py` → `timing.json`（每句起止）+ `mix.wav`（人声归一化 + 低音量 BGM + 换段音效）。
6. `python build.py` → `comp.html`；先用 shot.py 抽几帧截图检查溢出、遮挡（上一条视频 4:55 有一张卡片压住了上一张底边，这一步要抓出来）。
7. 渲染：`bash run_render.sh`（render.py --resume，可多次续跑）。完了检查 `_frames/` 里有没有 0 字节的 png，有就删掉再续渲。
8. 编码：`bash enc.sh` 分段编码，再 `ffmpeg -f concat` 拼接 + 合 mix.wav（AAC）。输出先写到本地临时目录再复制到网盘/同步目录，直接写网络盘曾出现 trailer 写入失败、文件损坏。
9. 封面：`cover.html`（16:9），`cover_multi.py` 一次出 9:16（抖音/视频号）、3:4（小红书）、4:3（B站动态/公众号）三个尺寸；每张都放头像（米白圆底 + 藏青环 + 黄环）。

## 真人口播流水线（2026-10-13 第一次跑通，样板 cases/zy）
喵叔拍竖屏口播 + 给文案（文案为准），我负责剪、字幕、包装和封面。配音不再用 TTS，长视频也由他本人录。
1. 抽音频：`ffmpeg -i 原视频 -ac 1 -ar 16000 a16.wav`。
2. ASR：`python asr.py`（faster-whisper small，CPU int8，initial_prompt 填产品名和术语，word_timestamps=True）→ `asr.json`。
3. 定剪辑区间：看 asr.json 和波形，去掉开头空白、重复念的句子（只留最后一遍）、超过约1秒的长停顿，写进 `cut.py` 的 K 列表 → `keep.json`。cut.py 用 trim/atrim + 12ms 淡入淡出拼接，音频 highpass 70Hz + loudnorm -16 LUFS → `edit.wav`，画面抽成 `zyf/` jpg 帧序列。
4. 字幕：`fix.txt` 一行对应 asr.json 一段，内容照文案人工改对（数字用阿拉伯数字，`|` 是字幕内换行，`#DROP` 表示删掉的段），`python subs.py` 按 keep.json 把时间映射到剪辑后时间轴 → `subs.json`。
5. 违禁词扫描：subs.json 和 tpl.html 里所有卡片文字过一遍上面的违禁词表，再渲染。
6. 包装：`tpl.html` + `python build.py` → `comp.html`（数字/IRR/AAA 自动加粗高亮）。版式：开头约3秒砸字钩子 → 人物大画面 → 讲数据时人物缩到左上角圆形小窗、数据卡弹出 → 讲完放大回正中；字幕在卡片下方，底部约370px留给平台按钮；片尾免责声明+品牌。小窗按开头测一次的脸中心固定裁切（tpl.html 里的 fx,fy）。
7. 抽帧检查：`python shot.py 输出.png 时间点...` 拼一张缩略图，查溢出、遮挡、脸是否居中、字幕是否对得上。
8. 渲染：`bash run.sh`（render.py --resume --sfx edit.wav，1080×1920），可断点续跑。
9. 封面：`python cover_gen.py` 出 9:16 和 3:4，真人圆窗用原片里表情自然的一帧，脸居中。
10. 交付前：确认成片存在、能播放、时长和音量正常（ffprobe / volumedetect）。

配色按内容选，不固定。已用过两套：冷灰白底+宝蓝 #2346FF（条款类样片）；深蓝金（产品对比：深蓝底 #0B1D45→#060F2A、金色 #F3D08A/#D9B26A 代表一方、浅蓝 #BFD3FF 代表另一方，逐年数据卡+关键年份盖章）。

## v3 增补（2026-10-13）：借鉴「固定舞台·元素生长」长科普
来源：喵叔发的一条利率主题视频号参考（9:16、8 分半、黑底霓虹数据、全片无硬切）。喵叔说「把好的搬了就行」。
**结构**
- 5 分钟以上长视频：开头放章节目录 01–0N，跟口播一条条点亮。
- 每屏顶部章节栏：左上「03 章节名」编号徽标，右上一排短线表示进度（当前章高亮）。任何模板都可加，放在顶部安全区内。
- 章节名优先用问句（「这条条款，坑在哪？」）。
**数据表达（新增组件）**
- 单个大数字占全屏、发光强调，一屏只讲一个数（IRR、分红实现率、差额；含分红数据仍标「演示利益/含不保证红利/以合同为准」）。
- 点阵图：100 个小圆点表示比例（「100 个投保人里有几个…」），用于发病率、理赔率等，数据注明来源+日期。
- 仪表盘指针：弧线先画出，指针再落定，用于「保障够不够」「健告严不严」这类程度判断。
- 因果环：一圈节点+箭头依次亮起，讲连锁影响，语气克制，不制造焦虑。
**动效**
- 「固定舞台」作为一镜到底之外的另一种镜头语言：镜头不动，元素在原地生长、变形，上一屏的字变形成下一屏标题，全片不硬切。适合数据密集的长科普；按内容选用，不替代一镜到底默认。
- 元素跟口播踩点：用逐字时间轴，说到哪个词，对应元素才出现。
**不照搬**
- 纯黑+多色霓虹只作「宏观/利率」类主题的备选配色，不当默认。
- 品牌「喵叔说保」与片尾免责照常保留；字幕不出现「利息」「比存款」等禁用词。
